# Как обновлять ASTRAVA V5

Текущая версия — **V5.1.3**. Готовое обновление находится в самом сайте и автономной сборке. Отдельный `.patch` для их запуска не требуется.

## Обновить сайт

1. Перед переносом своей коллекции скачай свежий JSON через «Хранилище».
2. Открой [актуальный обзор ASTRAVA](https://geraltschwarzenegger-svg.github.io/myTierAnime/?overview=1&release=5.1.3).
3. Для переноса коллекции в другой браузер импортируй собственный экспорт. При восстановлении выбирай нужный режим импорта: замена или объединение.

Тема, атмосфера и новые рамки переносятся отдельным JSON через «Студию». Экспорт оформления и резервная копия аниме имеют разное назначение.

Режим галереи скрывает вступление с иллюстрацией. Чтобы вернуться к нему, нажми на логотип или «Обзор». Ссылка выше тоже открывает обзор.

## Обновить автономную копию

1. Сохрани свою текущую коллекцию в JSON.
2. Скачай [актуальный автономный HTML](https://raw.githubusercontent.com/geraltschwarzenegger-svg/myTierAnime/main/NEWAnime%20tier%20list11-08-2026.html).
3. Открой скачанный HTML в браузере. При необходимости импортируй свой свежий JSON.

HTML содержит приложение, 73 опубликованных постера, шрифты и встроенные иллюстрации, включая новую обсерваторию. JSON со списком автора [скачивается отдельно](../anime-tierlist-2026-10-11.json); для восстановления собственных изменений используй свой экспорт.

## Что стало со старым патчем

`animetierlistchangesV2.patch` был снимком изменений ранней версии: дождь, статистика, перетаскивание, оформление тиров и футера. Он заменял одну длинную JSON-строку со всем HTML внутри старой оболочки.

Патч относился к файлу `Anime tier list2026`, отсутствующему в текущем проекте. Он не подключался сайтом и не участвовал в сборке. Ряд его функций уже присутствует в V5, а оформление и эффекты развивались дальше.

Старый патч удалён из актуального дерева файлов. При необходимости его можно [посмотреть или скачать из истории](https://github.com/geraltschwarzenegger-svg/myTierAnime/blob/3f3146c008139da0b814c10fcc78468508b3727c/animetierlistchangesV2.patch). Текущие изменения удобнее читать по коммитам и описанию релиза.

## Публикация сайта

GitHub Pages получает отдельную сборку файлов, нужных сайту, через Actions. [Процесс публикации и проверка статуса](pages-deployment.md). Исходники и архивы хранятся в репозитории, но в публикуемый сайт не копируются.
