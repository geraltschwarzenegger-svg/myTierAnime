# myTierAnime

Личный аниме тир-лист — один самодостаточный HTML-файл: `опрейдтирлист2807.html`.
Открывается двойным щелчком, интернет нужен только для загрузки обложек.

Список начинается **пустым**: встроенного набора тайтлов нет, наполняешь сам —
по одному, списком или импортом JSON.

## Где хранится список

Каждое изменение (тир, название, обложка, дата просмотра, реакция, порядок карточек)
записывается сразу в три места:

| Слой | Когда используется |
|---|---|
| `localStorage` | основной слот, пишется синхронно в момент правки |
| `IndexedDB` | зеркало на случай, если браузер вычистит `localStorage` |
| `.json` на диске | если подключить файл кнопкой **Хранилище → Подключить файл** (Chrome / Edge) |

При запуске берётся самая свежая копия по метке `savedAt`. Плашка слева внизу
показывает состояние записи; нажатие на неё открывает раздел «Хранилище».

Подключённый файл удобно положить в папку облака: тогда список переживает
и переустановку браузера, и скачивание новой копии HTML.

## Свои тиры, фон и защита

**Тиры.** «Настройки → Тиры»: имя, метка, цвет из палитры, порядок, добавление и
удаление (до восьми). Верхний тир получает корону и золотое оформление — это
привязано к позиции, а не к букве. При удалении тира его тайтлы переезжают в
соседний, ничего не пропадает.

**Фон.** Готовые сцены или своя фотография — файлом с диска (лежит в IndexedDB,
интернет не нужен) либо ссылкой. Затемнение, размытие, насыщенность и положение
настраиваются: без них текст тонет в светлой картинке.

**Защита.** Пароль шифрует список прямо в хранилище: PBKDF2 (250 000 итераций)
для ключа, AES-GCM 256 для данных. В localStorage лежит шифротекст — названия
оттуда не вытащить. Есть экран блокировки и автозапирание после 15 минут без
действий. **Восстановления нет**: забытый пароль означает потерю списка, поэтому
перед включением приложение требует экспорт.

## Правило про обложки и даты

То, что введено руками, не перетирается ничем. Встроенный каталог обложек
(`COVERS` в коде) подставляется только там, где ссылки нет вообще. Заменить свои
ссылки на каталожные можно только вручную — кнопкой «Обложки из каталога».

Импорт JSON спрашивает режим:

* **Заменить всё** — список становится ровно таким, как в файле;
* **Обновить обложки и даты** — список остаётся свой, но у совпадающих по названию
  тайтлов подтягиваются обложка, дата просмотра и реакция из файла.

Перед каждой записью сохраняется резервная копия предыдущего состояния —
«Хранилище → Откатить к копии».

## Сайт на GitHub Pages

В репозитории три варианта одного приложения:

| Файл | Для чего |
|---|---|
| `опрейдтирлист2807.html` | офлайн-копия — шрифты и html2canvas зашиты внутрь, интернет нужен только для обложек |
| `index.html` | версия для сайта, ~300 КБ — те же шрифты берутся с Google Fonts |
| `data.json` | опубликованный список, его видят все посетители |

### Как включить

1. Сделать репозиторий публичным (бесплатные Pages работают только с публичными).
2. Settings → Pages → Source: **Deploy from a branch** → `main` → `/ (root)`.
3. Через минуту сайт откроется по адресу
   `https://<владелец>.github.io/myTierAnime/`.

### Режим владельца

Гость всегда видит `data.json`. Чтобы править список прямо на сайте и публиковать
одной кнопкой:

1. GitHub → Settings → Developer settings → **Fine-grained tokens** → Generate new token.
   Repository access: **Only select repositories** → этот репозиторий.
   Permissions → Repository permissions → **Contents: Read and write**.
2. На сайте: «Хранилище» → «Режим владельца» → вставить токен → «Проверить и включить».
   Владелец и репозиторий подставляются из адреса страницы сами.
3. В шапке появляется кнопка **«Опубликовать»**. Пока есть неопубликованные правки,
   она горит золотом; после отправки показывает галочку.

Токен лежит в `localStorage` этого браузера и никогда не попадает в `data.json` —
публикуется только состояние списка. Права токена узкие: один репозиторий, только
содержимое. Публикация идёт через GitHub Contents API прямо из браузера, сервера нет.

Правки без токена никуда не уходят и остаются локальными — гость может двигать
карточки у себя, на сайт это не влияет. Вернуться к опубликованной версии можно
кнопкой «Показать версию с сайта».

## Как править код

HTML — это бандл: приложение лежит внутри как JSON-строка в
`<script type="__bundler/template">`, а шрифты — base64 в
`<script type="__bundler/manifest">`. Править приложение прямо в этой строке
невозможно, поэтому в репозитории лежит распакованный исходник `src/app.html`
и скрипт сборки:

```bash
# распаковать бандл в редактируемый вид (перезапишет src/app.html)
python3 tools/bundle.py unpack "опрейдтирлист2807.html" src/app.html

# ... правки в src/app.html ...

# собрать обратно: перезаписывается только строка с шаблоном,
# манифест шрифтов остаётся байт-в-байт
python3 tools/bundle.py pack "опрейдтирлист2807.html" src/app.html
```

Веб-версия собирается оттуда же:

```bash
# index.html: встроенные шрифты и html2canvas заменяются на CDN
python3 tools/mksite.py src/app.html index.html
```

Источник истины для приложения — `src/app.html`; и бандл, и `index.html` — сборки
из него, так что после правок надо запускать оба скрипта.
