# Бетатест myTierAnime

[Открыть интерактивный бетатест](https://geraltschwarzenegger-svg.github.io/myTierAnime/betatest/) · [Видео, 6 секунд](https://geraltschwarzenegger-svg.github.io/myTierAnime/betatest/preview.mp4)

Отдельный тест оформления: новые эмблемы S/A/B/C, кристалл вместо куба и переливы постеров. Можно менять материал кристалла, свечение и ставить анимации на паузу. По нажатию на постер открываются даты просмотра.

Основной сайт и его данные не изменены. Демо не пишет в хранилища и не отправляет запросы к API. Обложки, шрифты и пример дат встроены в HTML. На устройствах с уменьшением движения анимации включаются кнопкой «Включить».

Для GitHub Pages, публикующего ветку `main` из корня репозитория.
