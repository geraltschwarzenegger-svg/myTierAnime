# Astral Studio · источник оформления ASTRAVA V5

Студия встроена в `src/app.html` и публикуется вместе с V5.0.0. Здесь хранятся поддерживаемые CSS/JS-исходники, установщик для старых HTML-копий и браузерная проверка.

## Внесение изменений

1. Измени `studio.css` и/или `studio.js`.
2. Выполни `python3 tools/sync-studio.py` из корня репозитория.
3. Собери основной HTML, Worker-HTML и автономный файл обычными `tools/mksite.py` и `tools/bundle.py`.

`tools/test/studio.test.mjs` проверяет совпадение вставки с исходниками, единственную установку, CSP через общие тесты и встраивание всех опубликованных постеров в автономный файл. Сборщик сайта также переносит локальные постеры в статику Worker. Бандлер не меняет исходные URL в JSON-коллекции.

## Состояние

Ключ `anime-tierlist-astral-appearance-v1` содержит только оформление и собственный набор. Коллекция, даты, реакции и время просмотра не записываются. JSON оформления имеет `application: "myTierAnime.appearance"`, `schema: 1`; прежний идентификатор сохранён ради переносимости.

Выбор мира канонически хранится в Студии. Старая панель и явные сцены являются входами в тот же setter. Обёртка `applyBg()` восстанавливает мир после фоновых операций. Старое `FX.atm` поддерживается как совместимое зеркало. Переключатель частиц синхронизируется также между вкладками.

История отмены хранит до 12 снимков конфигурации в памяти текущей сессии. Один жест ползунка — один шаг. Другая вкладка заменяет конфигурацию и очищает локальную историю отмены. Сохранённый собственный набор переносится через локальное хранилище; экспорт оформления содержит текущие настройки.

## Рендеринг

Один погодный канвас: до 56 частиц на компьютере, до 28 на телефоне, не чаще 25 кадров/с. Старый ambient loop останавливается, когда `AstralStudio.ownsAmbient` истинен. Погода останавливается в лёгком режиме, без движения, при скрытии страницы, экспорте или открытом диалоге. Декоративные SVG не перехватывают нажатия.

Наблюдатели ограничены перерисовкой предпросмотра/демонстрации и классами `body` для жизненного цикла экспорта. Обход всего DOM по наведению не используется.

## Проверки

```sh
python3 -m unittest discover -s addons/astral-studio -p test_install.py
node --test --test-isolation=none tools/test/*.test.mjs site/test/*.test.mjs
node addons/astral-studio/studio.browser.cjs --exports --offline
node tools/test/journey.browser.cjs
```

Для браузерных проверок нужны Playwright и Chromium. В подготовленной среде Chromium расположен в `/usr/bin/chromium`; тесты других разделов поддерживают `CHROMIUM_EXECUTABLE`. `--live` проверяет публичный сайт, используя проверяемый TLS транспорт Node для загруженных ресурсов; отключение проверки сертификатов не применяется.

## Установщик старых копий

`install.py` остаётся инструментом для **старой копии V4.2 без Студии**. Он создаёт отдельный выходной HTML, ставит предохранитель прежнего рендерера и пересчитывает CSP. Текущая V5 уже содержит Студию: повторная установка отклоняется. Для редактирования текущего проекта используй синхронизацию исходников выше.

Автономный HTML проверен с блокировкой всех внешних загрузок после ручного импорта коллекции. Прямой переход `file://` запрещён политикой тестового браузера; этот способ запуска в данной среде не подтверждён. Встроенные 68 обложек доступны без внешнего хостинга. Новые пользовательские URL не включаются в файл автоматически.
