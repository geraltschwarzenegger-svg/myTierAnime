# ASTRAVA · серверная коллекция

Обновлённый интерфейс, вход по коду на почту, собственный адрес коллекции,
обратная связь и еженедельная сводка. Сервер работает на Cloudflare Workers + D1.
Текущий публичный сайт размещён на [GitHub Pages](https://geraltschwarzenegger-svg.github.io/myTierAnime/);
серверная версия проверена локально, отдельно в Cloudflare пока не опубликована.

## Устройство

| Слой | Реализация |
|---|---|
| Пользователи, коллекции, отзывы | D1 / SQLite |
| Сессия | подписанная HttpOnly-cookie и HMAC-отпечаток в таблице `sessions` |
| Код входа | HMAC в `login_codes`, срок 15 минут, пять попыток |
| Почта | Resend; настройка отправителя и домена зависит от аккаунта |
| Статика | Workers Assets; все ответы проходят через Worker |
| Безопасность | `src/security.mjs` и автоматически собранная `src/security-policy.mjs` |

Сессия действует 14 дней. Выход удаляет её запись из D1: сохранённая раньше
cookie больше не открывает аккаунт. Другие устройства остаются авторизованы.
Просроченные записи удаляются заданием по расписанию.

## Сборка

Из корня репозитория после изменения `addons/astral-studio/studio.css` или `studio.js` сначала синхронизируй Студию:

```bash
python3 tools/sync-studio.py
python3 tools/mksite.py src/app.html index.html
python3 tools/mksite.py src/app.html site/public/index.html
python3 tools/bundle.py pack 'NEWAnime tier list11-08-2026.html' src/app.html
```

Сборщик переносит шрифты и html2canvas в `public/assets/vendor` и пересчитывает
хеши CSP. Не правь готовый HTML вручную: изменения встроенного JavaScript
требуют новой сборки HTML и `security-policy.mjs`.

## Развёртывание

Нужны собственный аккаунт Cloudflare, D1, почта и случайный секрет сессии.
Примеры ID базы и `OWNER_EMAIL` в `wrangler.toml` нужно заменить своими.
Для воспроизводимой настройки использовался Wrangler 4.149.0 и Node.js 24.

```bash
cd site
npx wrangler@4.149.0 login
npx wrangler@4.149.0 d1 create anime-tierlist
# Впиши полученный database_id в wrangler.toml.
npx wrangler@4.149.0 d1 execute anime-tierlist --remote --file=schema.sql
npx wrangler@4.149.0 secret put SESSION_SECRET
npx wrangler@4.149.0 secret put RESEND_API_KEY
# Настрой OWNER_EMAIL и MAIL_FROM в wrangler.toml.
npx wrangler@4.149.0 deploy
```

`SESSION_SECRET` — не менее 32 байтов случайного материала; например,
сгенерируй его локально командой `openssl rand -base64 32` и передай через
`wrangler secret put`. Не записывай его в Git. Смена секрета завершит старые сессии.
Почтовый отправитель должен быть разрешён твоим аккаунтом Resend: тестовый
домен может ограничивать получателей. Для посетителей настрой свой домен.

Адрес Worker выдаст Cloudflare после развёртывания. Собственный домен
подключается в Workers → Custom Domains.

**При обновлении существующего сервера сначала примени `schema.sql`.**
Добавляются таблица сессий и индекс; старые коллекции не удаляются.
Пользователям со старыми cookie потребуется повторный вход. Оставь
`assets.run_worker_first = true`: иначе статика может миновать защитные заголовки.

## Локальный запуск

```bash
cd site
npx wrangler@4.149.0 d1 execute anime-tierlist --local --file=schema.sql
npx wrangler@4.149.0 dev --ip 127.0.0.1
```

Нужен отдельный локальный `database_id` в конфигурации и файл `.dev.vars`
со случайным `SESSION_SECRET`. Для разработки без почты можно добавить
`DEV_ECHO_CODE=1`, не задавая `RESEND_API_KEY`. Код возвращается в ответе
только на localhost, 127.0.0.1 или [::1]; на публичном домене он не возвращается.
Без настроенной почты production-вход не работает. `.dev.vars` и `.wrangler`
не должны попадать в репозиторий.

В облачной среде этой задачи настройки и база изолированы в
`/workspace/.environment/myTierAnime`. Запуск:
`bash /workspace/.environment/myTierAnime/start-worker.sh`, адрес
`http://127.0.0.1:8787`. Это внутреннее превью, а не публичный сайт.

## Защита API

Изменяющие запросы требуют `x-atl-request: 1`; Origin должен совпадать
с источником запроса, если присутствует. Межсайтовые запросы отклоняются;
CORS не разрешён. Непустое тело должно быть объектом JSON. Поток читается
с лимитом байтов: список 512 KiB, отзыв 32 KiB, прочее 8 KiB. Сервер проверяет
тиры, уникальные ID, размеры строк, реальные даты и ссылки на изображения.

CSP запрещает произвольные встроенные скрипты и eval. Ответы получают
nosniff, no-referrer, DENY, `frame-ancestors 'none'`, COOP и ограничения
Permissions-Policy; HTTPS также получает HSTS. Внутренние ошибки не выдаются
клиенту. Подробности и границы защиты — [SECURITY.md](../SECURITY.md).

## API

| Метод | Действие | Доступ |
|---|---|---|
| `GET /api/config` | режим и состояние входа | все |
| `POST /api/auth/request` | отправить код | пять запросов в час на адрес |
| `POST /api/auth/verify` | проверить и однократно погасить код | пять попыток на код, дополнительный лимит IP |
| `POST /api/auth/logout` | отозвать текущую сессию | текущий посетитель |
| `GET /api/me`, `PATCH /api/me` | профиль и настройки | вошедшие |
| `GET /api/list/:slug` | публичный список | все |
| `PUT /api/list` | записать свой список | владелец |
| `GET /api/lists` | каталог непустых списков | все |
| `POST /api/feedback` | отзыв владельцу | все, ограничение частоты |
| `GET /api/feedback` | прочитать входящие без изменения статуса | владелец |
| `POST /api/feedback/read` | отметить показанные ID прочитанными | владелец, защищённый запрос |

Проверка количества отзывов больше не помечает их прочитанными. Отметка
ставится после открытия входящих и относится только к показанным сообщениям.

## Проверки

Из корня, Node.js 24+, без сети и дополнительных пакетов:

```bash
node --test site/test/worker.test.mjs site/test/security.test.mjs tools/test/persistence.test.mjs
```

49 тестов: настоящий код Worker с Node SQLite вместо D1, почта через
перехваченный fetch. Проверяются вход, права, публикация, ограничения,
параллельные запросы, CSRF, отзыв сессий, размеры потока и хеши сборки.
Отдельно проверены настоящий локальный Worker с D1, браузерный вход,
публикация, PNG-экспорт под CSP и отклонение cookie после выхода.

Возможные следующие задачи: удаление аккаунта, ответы на отзывы в интерфейсе
и собственное хранилище обложек вместо внешних источников.
