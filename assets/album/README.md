# Альбом шедевров · S

Пять старых листов `01.webp`–`05.webp` содержат по три изображения. Они продолжают использоваться для 11 прежних кадров.

09.11.2026 четыре кадра переведены на отдельные широкие фотографии:

| Индекс альбома (с нуля) | Аниме | Изображение |
|---:|---|---|
| 3 | Человек-бензопила | `chainsaw-sakura-2026-11-09.webp` |
| 12 | Звездное дитя | `oshi-concert-2026-11-09.webp` |
| 13 | Реинкарнация безработного: История о приключениях | `mushoku-garden-2026-11-09.webp` |
| 14 | Клинок, рассекающий демонов | `kimetsu-wisteria-2026-11-09.webp` |

Это новые иллюстрации, пересозданные генератором по визуальным референсам пользователя и прежним кадрам проекта. Они не являются побайтными копиями присланных превью. Цвета, композиция и отдельные детали могут отличаться. Сохранены в WebP без дополнительного изменения композиции; исходные размеры, происхождение и имена результатов генерации записаны в `replacements.json`.

`src/app.html` содержит встроенные версии в JSON `albumOverrides`. Сборка сайта использует отдельные файлы, а автономный HTML получает встроенные данные. Четыре новые фотографии показываются целиком с сохранением пропорций; остальные кадры используют прежние смещения листов. Новые имена исключают показ прежних листов из кеша по тем же URL.
