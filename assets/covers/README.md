## Библиотека постеров V5

В `library/` находятся 68 локальных WebP-копий опубликованных постеров. `library.json` фиксирует исходную ссылку записи, реальный источник изображения, идентификатор аниме, размер и дату проверки. Для недоступных AniList-ссылок использовано точное сопоставление MyAnimeList → Kitsu. Исходные URL в `data.json` сохранены. Отображение использует локальную копию; автономный бандлер встраивает эти WebP как data-URL.
