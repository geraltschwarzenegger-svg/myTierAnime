# ASTRAVA Lab — план, архитектура и границы эксперимента

Тестовая ветвь развития ASTRAVA. Основной сайт и V5.0.0 не заменяются.
Дата первоначального проектирования: 06.11.2026; реализация и проверка: 07.11.2026.

## Что выбрано и почему

| Технология | Роль | Решение |
|---|---|---|
| HTML + CSS | Семантика, адаптивная страница, диалоги, галерея | Сохраняются; не переносятся в WebGL |
| TypeScript со строгой проверкой | Данные, настройки, сцена, интерфейс | Новая модульная основа вместо одного большого встроенного скрипта |
| Three.js + WebGL 2 | Объёмная геометрия, материалы, камера, свет | Рабочий рендерер лаборатории |
| GLSL | Небольшой эффект частиц и мягкая контактная тень | Выполняется на GPU; не требует вычисления каждой частицы на CPU |
| GLB / glTF 2.0 | Перенос моделей | Загрузка локального самодостаточного GLB и экспорт собственной эмблемы |
| Vite | Сборка, модули и сервер разработки | Отдельная сборка; библиотеки находятся на своём хостинге |
| Rust / WebAssembly | Возможные вычислительные модули | Не подключены: пока нет доказанного узкого места CPU. Rust сам по себе не улучшает модели, материалы и свет |
| WebGPU | Возможный следующий рендерер | Изучен, но в этой версии используется WebGL 2; WebGPU не заявлен как реализованный |

Rust и WebAssembly не были установлены и не сравнивались с JavaScript в бенчмарке. Вывод о выборе текущей архитектуры основан на задаче браузерной отрисовки и документации, а не на выдуманном измерении скорости Rust.

## План и критерии готовности

1. Изолировать тестовый проект и хранилища. Новый интерфейс использует `astrava-lab:v1:*`, копия V5 — `astrava-lab:classic:*`. База IndexedDB копии V5 также получает префикс. Отдельный URL GitHub Pages сам по себе не изолирует origin.
2. Сохранить опубликованный JSON без изменения записей. Контрольная сумма и коммит исходника находятся в `baseline.json`. В исходной копии 69 аниме, S/A/B/C = 15/23/16/15, 79 дат, 41 167 минут.
3. Выделить проверку данных и хронометража, хранилище, генераторы мешей, сцену и UI. Проверять код строгим TypeScript перед каждой сборкой.
4. Создать новое светлое оформление лаборатории: большая тёмная сцена, панель материалов и света, читаемая коллекция и привычная иллюстрация.
5. Создать четыре самостоятельных объёмных объекта: солнечный венец, нефритовый феникс, аметистовый архив и лунный гербарий. Объединять статические детали по материалам. У каждого объекта 2–3 меша; точные параметры — в `models.json`.
6. Добавить ручное вращение, кнопки приближения, клавиатуру, сброс, отключаемое медленное вращение и общую паузу. По умолчанию сам объект автоматически не вращается.
7. Согласовать атмосферу через один объект настроек. Ручной выбор отключает автоматическую связь с тиром. Качество и экспозиция не сбрасывают окружение. Четыре окружения лаборатории не подменяют девять атмосфер V5.
8. Добавить PNG и GLB. Проверять заголовок, размер и структуру входящего GLB. Запрещать внешние URI, чрезмерное число объектов/вершин и неподдерживаемое сжатие. Импортированная модель находится в памяти вкладки, на сервер не загружается.
9. Подключить все 69 аниме: поиск, фильтры, избранное, подробности, несколько дат, редактирование дат/минут, импорт и экспорт. Основной JSON не изменяется. Прежние функции V5 доступны в отдельном режиме совместимости.
10. Ограничить разрешение рендера. В лёгком режиме отключить частицы и постобработку. В детальном — включать дополнительное свечение только на широком экране. Останавливать анимацию в скрытой вкладке, вне экрана, под диалогом, на паузе и при reduced motion. При отсутствии WebGL оставить работоспособный интерфейс и статическое изображение.
11. Пройти модульные и браузерные проверки: реальная сцена, все тиры, JSON, GLB/PNG, несколько дат, календарь, мобильные размеры, ошибки импорта, контекст WebGL и защита исходных хранилищ.
12. Опубликовать только лабораторию, приложить результаты и ограничения. Основной проект обновлять после отдельного решения владельца.

## Что не выдаётся за завершённую миграцию

Это самостоятельная лаборатория новой графики, а не полная перепись всех возможностей V5. Старое ателье рамок, альбом, прежние реакции и полные настройки работают в режиме совместимости. Они не перенесены в новые модули TypeScript. Настройки двух интерфейсов намеренно независимы.

Модели эмблем оригинальные, созданы процедурно в `src/models.ts`. Это не модели персонажей из Blender и не обещание уровня AAA. Экспорт GLB позволяет продолжить обработку в Blender. Мягкое свечение и детали можно оценить на своём устройстве; универсальные 60 FPS не гарантируются.

## Проверка плана перед реализацией

- Полная замена V5 на Rust отклонена: затраты и риск для редактора/сохранений не подкреплены выигрышем.
- Выбран постепенный подход: новый движок и новый интерфейс отдельно, старые функции доступны для сравнения.
- Процедурные модели подходят для эмблем; полноценные модели персонажей требуют отдельной подготовки в Blender или готовых лицензированных GLB.
- В тестовый интерфейс перенесён конкретный рабочий набор, а не все настройки V5. Это обозначено в интерфейсе и отчёте.
- Публичная тестовая публикация допускается только после проверки сохранений и реального браузерного прогона. Основной репозиторий не является целью деплоя.
